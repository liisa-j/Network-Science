This is the repo for Network Science Project: a Study of Estonian Runosongs’ Themes
-----------------------------------------------------------------------------------

The code for re-creating the runosong database can be found in the runodb_builder folder. 

The SQL-code that was used to query the database is found in final_view.sql. 

The runo2.csv file was created based on the final_view.sql query and is the input of the NSProject.ipynb. 

The Kihelkond_kuni_1917.shp is a shapefile from https://geoportaal.maaamet.ee/docs/haldus_asustus/ajaloolised/Kihelkond_kuni_1917.zip that is used in the visualisations.

The code for the project is found in the file NSProject.ipynb.

Also included are: Poster.pdf (poster for the project's presentation) 3 *.txt files that are targets of the posters QR codes.
